# Troubleshooting: tools

Problems with your codespace, Git, `gh`, or classroom50.org. For problems with
the day's Python code, use the **Help** page linked from your assignment.

| Problem | Fix |
| --- | --- |
| `No module named pytest` | The codespace is still loading. Wait a minute and paste the order again. |
| `gh` or `python` isn't recognized | The codespace is still loading. Wait a minute and paste the order again. Still there? Tell your teacher. |
| No terminal at the bottom | Choose **Terminal → New Terminal**. |
| The terminal wandered off (`No module named 'pirate_tools'`) | Close it (🗑️ trash can icon), open a new one (**Terminal → New Terminal**), and run the tests again. |
| Made a second codespace by mistake | Click **Sync Changes** in the one you were using first. Then delete the extra one (see [Codespace hours](codespaces.md#codespace-hours)). |
| Codespace won't start | The hours may have run out. Tell your teacher. Your synced work is safe on GitHub. See [Codespace hours](codespaces.md#codespace-hours). |
| Signed in as the wrong person | Your codespace belongs to whoever is signed in to github.com. Sign out, sign in as yourself, and open your own codespace. |
| Push is rejected | Someone (maybe you, on GitHub) changed the repository first. Click **Sync Changes** again. |
| No scorecard, ✅, or ❌ yet | Grading takes a minute or two after you sync. Refresh the page. Only `main` is graded. |
| Not on your usual computer | Any computer with a browser works. Sign in to github.com, open your repository, and click **Code → Codespaces**. Pick the codespace that's already there. |

Still stuck? Ask a crewmate, then your teacher.
